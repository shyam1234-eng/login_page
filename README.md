# Login Page Project

A simple static login page project built with HTML, CSS, and JavaScript.

## Project Overview

This project contains three pages for a basic authentication UI:

- `login.html` - login form
- `reset.html` - password reset form
- `signup.html` - sign-up form

It uses a shared stylesheet:

- `public/style/styles.css`

And a JavaScript file:

- `scripts/login.js`

## Features

- Responsive layout for desktop and mobile
- Clean form design with username and password fields
- Shared CSS styling across all pages
- Placeholder JS file included for future login/reset/signup behavior

## Folder Structure

```text
login.html
reset.html
signup.html
public/
  style/
    styles.css
scripts/
  login.js
```

## How to Use

1. Clone the repository or download the files.
2. Open `login.html` in your browser to view the login page.
3. Open `reset.html` to view the password reset page.
4. Open `signup.html` to view the sign-up page.

## Notes

- The HTML pages load CSS from `public/style/styles.css`.
- The JavaScript file `scripts/login.js` is included but currently contains a placeholder value.
- Update the links and script behavior as needed for a real authentication flow.
